# AI Resume Analyzer

An interactive web application that analyzes a resume and compares it with a job description to identify matching and missing skills.

## Features

- Upload resume in PDF format
- Extract text from resume
- Detect technical skills
- Analyze job description
- Calculate resume-job match percentage
- Identify matched skills
- Identify missing skills
- Visualize skill comparison
- Provide skill improvement recommendations

## Technologies Used

- Python
- Streamlit
- PyPDF2
- Pandas
- Matplotlib

## How It Works

Resume PDF → Text Extraction → Skill Detection → Job Description Analysis → Skill Matching → Match Score → Visualization → Recommendations
